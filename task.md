# Tasks: Novelist Workspace SPA

## Objective
Build a web-based workspace for novelists to manage their writing process.

## Requirements
- **Tech Stack**: ReactJS, Tailwind CSS (for styling), Supabase (for database).
- **Core Modules**:
  - [x] **Planner**: Character & Location wiki.
  - [x] **Editor**: Rich-text writing interface with auto-save.
  - [x] **Tracker**: Daily word count visualization.

## Architecture
- Use a component-based structure (e.g., /components/Editor, /components/Wiki).
- Use a clean, distraction-free UI.
